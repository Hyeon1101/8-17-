-데이터(Fact) ➔ 정보(의미) ➔ 지식(규칙) ➔ 지혜(결정)

데이터베이스(db)
: 데이터 저장창고
-통합된 데이터(중복 없이 하나로)
-저장된 데이터(컴퓨터가 읽을 수 있게 저장장치에 담아둠)
-공용 데이터
-수시적 변용 데이터
-실시간 접근성

빅데이터
-양
-속도
-다양성(숫자, 영상, 음성, 위치정보, 댓글 등 데이터의 형태가 다양함)

데이터로 인한 변화
-사전 처리 ➔ 사후 처리: 데이터를 골라서 저장하는게 아닌 모두 저장해두고 나중에 분석, 처리함
-표본 조사 ➔ 전수 조사: 표본을 뽑아 조사 하는게 아닌 전수(전체)를 모두 조사함
-인과관계(Why, 이유) ➔ 상관관계(What, 결과): 유튜브 알고리즘의 원리

빅데이터의 부작용과 해결방법
-사생활 침해
ex) 고객의 구매 데이터를 분석해 동의 없는 쿠폰발송
해결방법: 동의제 ➔ 책임제(사전 동의는 의미가 없으니 피해 발생시 사후 책임을 지게 만드는 것)
-책임 원칙 훼손
ex) 범죄 예측 AI의 예측만으로 아무 행동을 하지 않은 사람에게 불이익을 줌(영화 <마이너리티 리포트>)
해결방법: 예측 결과만으로 사람을 처벌할 수 없게, 인간의 최종 판단과 책임 원칙 유지& 통계적 예측의 한계 인정
-데이터 오용
ex) 잘못된 데이터나 편향된 알고리즘, 데이터 맹신
해결방법: 알고리즈미스트(Algorithmist, 알고리즘이 편향이나 오류가 없는지 감시하고 해석해주는 전문가) 도입 & 알고리즘 설명 요구권

2과목) 

(문제 해결을 위한)문제를 분석하는 방법
-하향식 접근법 (Top-Down): 문제를 정확히 알 때 [순서: 탐색 ➔ 정의 ➔ 해결방안 ➔ 타당성 검토]
-상향식 접근법 (Bottom-Up): 문제를 정확히 모를 때
*중*디자인 사고(Design Thinking): 하향식과 상향식을 반복해서 왔다 갔다 하며 최고의 아이디어를 내는 방법

마스터 플랜-우선순위 결정
-시급성
-난이도
=보통 시급성이 높고 난이도가 낮은 일을 먼저 해야함

데이터 분석 팀 만들기
-집중형 조직
-분산형 조식
-*중*혼합형 조직(Hub & Spoke - 허브 앤 스포크): 집중형과 분산형의 장점만 합친 가장 이상적인 형태

회사의 분석 실력 점검
-준비도: 분석을 시작할 준비(인력, 데이터, 시스템, 문화 등)의 여력
-성숙도: 데이터 활용 수준
준비형: 준비도 낮음, 성숙도 낮음 (아직 아무것도 안 됨)
정착형: 준비도 낮음, 성숙도 높음 (기술은 좀 쓰는데 전반적인 준비 부족)
도입형: 준비도 높음, 성숙도 낮음 (장비랑 데이터는 갖췄는데 활용을 잘 못함)
확산형: 준비도 높음, 성숙도 높음 (완벽)
